# CR-001 – Incorporar multa por devolución tardía

| Campo | Detalle |
|---|---|
| ID | CR-001 |
| Solicitante | Dirección de Biblioteca |
| Fecha | 15/11/2026 |
| Descripción | Cobrar S/ 1.00 por día de retraso en la devolución de un libro. El usuario con multa pendiente no podrá realizar nuevos préstamos. |
| Justificación | Reducir el 18 % de devoluciones tardías del último semestre y mejorar la disponibilidad del material. |

| Prioridad | Alta |
